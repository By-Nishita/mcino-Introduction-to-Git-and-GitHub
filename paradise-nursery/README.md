# Paradise Nursery



Paradise Nursery is an online houseplant shopping application that allows users to browse and purchase beautiful indoor plants.



## Project Name



Paradise Nursery



## About the Project



Paradise Nursery is a React-based online plant shopping application. Users can explore different categories of houseplants, view plant details and prices, add plants to their shopping cart, and manage their cart items.



## Features



- Landing page with Paradise Nursery branding

- Get Started button

- About Paradise Nursery section

- Plant listing with multiple categories

- Plant images, names, and prices

- Add to Cart functionality

- Shopping cart with dynamic item count

- Increase and decrease item quantity

- Delete items from the cart

- Total cart amount calculation

- Checkout button

- Continue Shopping option



## Technologies Used



- React

- Redux Toolkit

- React Redux

- Vite

- CSS



## How to Run



npm install



npm run dev



Then open the local URL shown by Vite in the browser.
